# Router Console design system

The native Open Design design system is `user:router-console-design-system`, in the Router Console Design System workspace. This directory contains its exported semantic tokens, local fonts, component reference and operational examples. Read [DESIGN.md](DESIGN.md) and [SKILL.md](SKILL.md) before composing application pages.

The [design brief](../docs/DESIGN_BRIEF.md) and [product plan](../docs/PRODUCT_PLAN.md) define the product direction. Use the existing project and attached design system through the [Open Design workflow](../docs/OPEN_DESIGN.md); validate and export package changes before updating this copy.

Local project links are recorded in the Git-ignored `.opendesign.local.json` at the repository root. IBM Plex font assets and their licences are bundled in `fonts/`.
