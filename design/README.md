# Router Console design system

The native Open Design design system is initialized as `user:router-console-design-system`, in the Router Console Design System workspace. Its generation run was canceled before tokens and component previews were produced. The draft is not yet an implementation-ready design package.

The product-specific [design brief](../docs/DESIGN_BRIEF.md) and [product plan](../docs/PRODUCT_PLAN.md) define the intended direction. Follow the [Open Design workflow](../docs/OPEN_DESIGN.md) to resume authoring and export the validated package into this directory.

Local project links are recorded in the Git-ignored `.opendesign.local.json` at the repository root. Local IBM Plex font assets and their licences were prepared in the Open Design workspace and remain available for the resumed run.
